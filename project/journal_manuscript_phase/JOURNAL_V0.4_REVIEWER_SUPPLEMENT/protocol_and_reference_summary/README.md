# Protocol and reference

The included records retain the prospectively specified 27-condition and 21-pair design, legal history graph, observation contract and independent Y labels. Historical NOT_STARTED/FROZEN strings describe the document at preparation, not the final execution status. The final coverage tables control what was observed.

Y is a predeclared source/configuration/schedule label, not generated from O1/O2/O3 and not a complete second executable simulator. Normal target calls create history. O1 is the entire return tuple for the declared entrypoint. O2 includes public pre/post getters and declared events; Aurigami update-prefix events are not attributed to a later pure read. Fathom peekPrice is an intervention, never an extra observation call.

All 21 pairs remain in the ledger. PF01–PF05/PF08 are non-comparable. The expected labels for missing conditions are expectations only. No pair is replaced. O3 contains retained trace results with stack/memory/storage collection disabled; no nonpublic slot set was populated.
